# Implementation Plan: English README, Preview Images and Bode Plots

**Branch**: `fix/adapt-readme-english` (feature dir `001-english-readme-assets`) | **Date**: 2026-10-30 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `/specs/001-english-readme-assets/spec.md`

## Summary

Translate `README.md` and the package preview image (`assets/social-preview.svg`, re-rendered
to `.png`) from Portuguese to English without changing structure or numbers, renaming the
example identifier `rede` to `network`. Add a Bode plot of the tutorial's RC low-pass
example to section 6: a reproducible Plots.jl snippet in the README, a generator script in
a separate `scripts/` environment, and the resulting SVG in `assets/`. The package API and
its dependencies do not change.

## Technical Context

**Language/Version**: Julia (package supports ≥ 1.10; `scripts/` environment needs ≥ 1.11
for `[sources]`); Markdown; SVG

**Primary Dependencies**: Plots.jl + GR (scripts environment only); librsvg
`rsvg-convert` and Fira Code / Inter fonts for rasterizing the preview

**Storage**: files in the repository (`README.md`, `assets/`, `scripts/`)

**Testing**: existing `Pkg.test()` suite; manual README example check; grep for Portuguese
words; visual inspection of images (see [quickstart.md](quickstart.md))

**Target Platform**: GitHub README rendering (light and dark themes), Julia REPL

**Project Type**: Julia library — documentation and assets change only

**Performance Goals**: N/A

**Constraints**: no new dependency in the package `Project.toml`; preview stays 1280 × 640
with unchanged design; Bode figure readable on light and dark backgrounds

**Scale/Scope**: one README (~255 lines, 9 tutorial sections), one SVG + PNG pair, one new
figure, one small script
