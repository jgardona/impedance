# Data Model: English README, Preview Images and Bode Plots

This feature has no runtime data. The "entities" are documentation artifacts and the
terminology that ties them together.

## Artifacts

| Artifact | Path | Source of truth | Regenerated by |
|---|---|---|---|
| README | `README.md` | itself | hand-edited |
| Preview image (vector) | `assets/social-preview.svg` | itself | hand-edited |
| Preview image (raster) | `assets/social-preview.png` | the SVG | `rsvg-convert` (see [quickstart](quickstart.md)) |
| Bode figure | `assets/bode-rc-lowpass.svg` | `scripts/bode.jl` | `julia --project=scripts scripts/bode.jl` |
| Bode script environment | `scripts/Project.toml` | itself | — |

**Relationships**

- README → embeds both `social-preview.svg` (top) and `bode-rc-lowpass.svg` (section 6).
- README section 6 snippet ≡ plotting body of `scripts/bode.jl` (must stay identical).
- `social-preview.png` must match `social-preview.svg` (same text, 1280 × 640).

**Validation rules** (from spec FRs)

- No Portuguese text in any artifact (FR-001, FR-008, FR-014).
- README keeps sections 1–9 and the quick reference in the same order (FR-002).
- Bode data: R = 1 kΩ, C = 1 µF, `logfreqs(10, 1e5, 200)`, fc = `cutofffrequency(R, C)`
  (FR-010, FR-011).
